# Contributing

Thank you for contributing.

## Role of AI agents in this repository

This project shows how AI agents can support open source:

- Copilot instructions define contribution and security expectations.
- PR validation checks markdown and workflow quality on every pull request.
- CodeQL scans repository workflows for security problems.

## Pull request process

1. Create a focused branch for one change.
2. Keep pull requests small and explain the purpose clearly.
3. Ensure all pull request checks pass.
4. Resolve security findings before merge.
